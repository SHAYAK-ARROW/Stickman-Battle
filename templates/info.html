Security & Sandboxing

User scripts execute in an isolated Python subprocess worker guarded by an Abstract Syntax Tree (AST) visitor. System primitives (eval, exec, open) and deep nested loops are strictly prohibited to prevent denial-of-service.

📐

Trigonometric Physics

Projectile spells trace genuine mathematical curves ($\sin, \cos, \tan, \sec, \csc, \cot$) rendered dynamically in 60 FPS on HTML5 Canvas with weapon length hitboxes and mutual sword parries.
