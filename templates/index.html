Security & Sandboxing

User Python code executes in an isolated subprocess protected by an Abstract Syntax Tree (AST) validator. System primitives (eval, exec, open) and infinite loops are strictly blocked to ensure 100% fair and safe combat.

📐

Trigonometric Physics

Projectile spells compute real-time mathematical wave functions (sin, cos, tan, sec, csc, cot) dynamically mapped to HTML5 Canvas weapon hitboxes at 60 FPS.
