Category Command Description Example
Movement move(step) Walk forward move(2)
Movement run(step) Run forward run(3)
Movement dash(step) Dash forward quickly dash(4)
Movement dodge(step) Dodge backward to evade an attack dodge(3)
Movement crouch() / duck() Crouch to evade high sword strikes crouch()
Movement jump(power) Jump straight up jump(5)
Movement long_jump(step, power) Jump forward long_jump(3, 5)
Movement bend(angle) Bend the stickman torso (-45 to 45 deg) bend(20)
Movement flip() Turn to face the opposite direction flip()
Combat attack() Strike with the sword (1 damage) attack()
Combat heavy_attack() Deliver a heavy strike (2 damage or break shield) heavy_attack()
Combat throw_sword() Throw the sword at a distant opponent throw_sword()
Combat block() Block incoming attacks for 30 frames block()
Combat swing() Perform a quick horizontal sword slash swing()
Combat project(angle, power) Propel forward with angled trajectory project(45, 5)
Combat set_sword(length, angle) Set sword length (30-80 px) and angle set_sword(65, 10)
Combat set_shield(length, angle) Set shield length (20-70 px) and angle set_shield(50, 35)
Combat set_right_hand(x, y) Set the right hand coordinates set_right_hand(240, 350)
Combat set_left_hand(x, y) Set the left hand coordinates set_left_hand(220, 360)
Combat move_right_hand(dx, dy) Offset the right hand coordinates move_right_hand(5, -10)
Combat move_left_hand(dx, dy) Offset the left hand coordinates move_left_hand(-5, -10)
